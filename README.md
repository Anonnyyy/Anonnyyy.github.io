## 查看完整网页

下载或克隆此仓库，用浏览器打开 `index.html`。三个项目页、论文 PDF、视频和图片均包含在本仓库中，支持本地访问。

仓库保持 **Private**，没有启用公开 GitHub Pages。GitHub 上的 `index.html` 文件页只显示源码；真正的网页需本地打开或使用带访问控制的私有托管。

## 页面结构

- `index.html`：个人作品集首页。
- `projects/three-point-controller/`：三点控制器论文项目页。
- `projects/rcar-humanoid-reaching/`：RCar / 本科毕设项目页。
- `projects/signal-separation-2023/`：电赛项目页。

论文项目页使用常见学术展示结构：标题、资源链接、演示视频、摘要、方法图与实验结果。科学内容与素材来源记录在各项目的 `SOURCE_NOTES.md`。
